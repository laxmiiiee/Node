# Node.js Interview Revision — Master Index

This revision pack is built around the Node.js topics we covered for the Comcast/full-stack interview.

## Phase order

1. Node Runtime & Architecture
2. Asynchronous Node.js & Event Loop
3. HTTP Fundamentals
4. Express & API Architecture
5. Authentication & Authorization
6. Error Handling, Validation & Production API Practices
7. Streams, Buffers & File/Network I/O
8. Databases & Node.js
9. Caching, Redis & Performance
10. Security
11. Testing & Observability
12. Node.js System Design & Interview Patterns
13. Rapid Revision / Interview Questions

## How to use

For a two-day interview sprint:
- First pass: read the mental models and flow diagrams.
- Second pass: read the interview traps and compare concepts.
- Final pass: answer the questions aloud without looking.

The goal is not memorization. The goal is to be able to explain **what happens, why it happens, and what trade-off you chose**.
